# HU Launcher

Cara membuat APK:
1. Buka folder ini di Android Studio (Hedgehog atau lebih baru), tunggu Gradle sync selesai (perlu internet).
2. Menu Build > Build APK(s). Hasil: app/build/outputs/apk/debug/app-debug.apk
3. Pasang APK ke head unit, tekan Home, pilih "HU Launcher" > Selalu.
4. Izinkan Lokasi saat diminta. Ketuk ikon musik di widget untuk mengizinkan akses media (Notification access).

Alternatif tanpa Android Studio: upload folder ini ke repository GitHub baru. Tab Actions > Build APK akan membuat
app-debug.apk yang bisa diunduh dari bagian Artifacts (sekitar 3-5 menit).
